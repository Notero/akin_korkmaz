# High-Performance C++ WebSocket Server

A lightweight, low-latency WebSocket server implementation using C++ and the uWebSockets library.

## Project Inventory

- **[src](./src)**: The C++ source code containing the core server logic and WebSocket event handlers.
- **[resource](./resource)**: Static assets and configuration files used by the server.
- **`CMakeLists.txt`**: The standard build configuration for cross-platform C++ compilation.
- **`build/`**: The local directory for compiled binaries and build artifacts.

## Core Features
- **Low Latency**: Optimized for minimal overhead in real-time data transmission.
- **Event-Driven**: Efficiently handles multiple concurrent connections with high throughput.
- **Modern C++**: Leverages contemporary C++ standards for robust and safe networking.

## How-To
- **Build**: Use `cmake .` and `make` within the root directory to compile the server.
- **Execution**: Run the generated binary from the `build` or root directory.
