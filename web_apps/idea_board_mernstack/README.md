# Idea Board: MERN Stack

A collaborative brainstorming platform built with the modern MERN stack (MongoDB, Express, React, and Node.js).

## Project Inventory

- **[client](./client)**: The React-based frontend application for interactive idea submission and visualization.
- **[server](./server)**: The Node.js/Express backend API responsible for data handling and persistence.
- **`test.mmd`**: A Mermaid diagram file detailing the system's architecture and flow.

## Highlights
- **Real-Time Interactivity**: Responsive React-based UI for dynamic content updates.
- **Scalable Backend**: RESTful API design using Express and MongoDB for flexible data storage.
- **Collaborative Flow**: Designed for users to share and refine brainstorming ideas effectively.
