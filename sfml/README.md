# SFML: Graphics & Multimedia Learning

A focused exploration of the Simple and Fast Multimedia Library (SFML) for creating 2D graphics, interactive windows, and multimedia applications in C++.

## Project Inventory

- **`sfml_learning.cpp`**: Core file for experimenting with the SFML library, including window creation, shape rendering, and basic event handling.

## Highlights
- **Graphics Pipeline**: Managing the rendering loop and window contexts.
- **Event Handling**: Capturing keyboard and mouse input for interactive experiences.
- **Asset Integration**: Exploring the integration of textures, sprites, and fonts.

---
*Maintained as a hobby project to learn the basics of 2D game and graphics development.*
