# Android Studio Projects

This directory contains a collection of mobile applications created while exploring the Android development ecosystem. These projects range from utility tools to interactive games, focusing on Gradle-based builds and Android UI paradigms.

## Project Inventory

- **[custom_Calculator](./custom_Calculator)**: A custom-designed calculator app for personalized daily calculations.
- **[mine_Sweeper](./mine_Sweeper)**: A mobile implementation of the classic Minesweeper puzzle game.
- **[mock_xrpWallet](./mock_xrpWallet)**: A prototype XRP wallet designed for experimenting with XRPL interaction concepts.
- **[pokemon_SearchByID](./pokemon_SearchByID)**: A lightweight utility to retrieve Pokémon data using specific IDs.

## Highlights
- **Architecture**: Gradle-managed multi-module projects.
- **Tools**: Developed with Android Studio, leveraging contemporary Android APIs.
- **Goal**: Practical application of mobile development principles and UI/UX design.
