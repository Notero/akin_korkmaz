# Repository

A comprehensive collection of software engineering projects, academic assignments, and personal tools spanning multiple platforms and languages. This repository serves as a centralized hub for cross-disciplinary technical development.

## Directory Inventory

- **[android_studio_projects](./android_studio_projects)**: Mobile applications developed using Android Studio and Gradle.
- **[computer_science_code](./computer_science_code)**: Academic projects, algorithms, and data structures implemented primarily in C and Java.
- **[custom_scripts](./custom_scripts)**: Interactive web experiments and automation tools.
- **[security](./security)**: Cryptographic implementations and security-related algorithms.
- **[sfml](./sfml)**: Graphical and interactive learning projects using the SFML library.
- **[terminal_tools](./terminal_tools)**: Command-line utilities for productivity and blockchain interaction.
- **[web_apps](./web_apps)**: Full-stack web applications utilizing LAMP, MERN, Spring, and high-performance WebSocket stacks.
- **[xrpl_qt_interface_for_rippled](./xrpl_qt_interface_for_rippled)**: A Qt-based desktop interface for interacting with the XRP Ledger.

*This repository is maintained for both educational reference and personal utility.*
