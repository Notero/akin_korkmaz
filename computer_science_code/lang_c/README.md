# C Programming: Algorithms & Systems

A deep dive into low-level programming, focusing on system architecture, data structures, and algorithmic implementation in C.

## Directory Inventory

- **[computer_design_project](./computer_design_project)**: MIPS architectural simulator (SPIMcore).
- **[custom_terminal](./custom_terminal)**: Custom shell (`mysh.c`) for basic UNIX-like command interaction.

## Core File Inventory

### Games & Utilities
- `battle_ships_terminal_game.c`: A full-featured terminal implementation of Battleships.
- `reciperion.c / .h`: A modular recipe management system.
- `vase_project.c`: A specific project focused on resource handling.

### Data Structures & Algorithms
- `binary_search_tree.c`: Implementation of binary search trees and traversals.
- `Tries.c`: A prefix tree implementation for efficient string retrieval.
- `list_implementation.c / queue_implementation.c`: Foundational data structures.
- `flood_fill.c`: Recursive grid-based filling algorithm.
- `common_search_sort_functions.c`: Centralized library for searching and sorting.

### Systems & Concepts
- `alu_insfetch.c`: Logic for instruction fetching and ALU operations.
- `file_system_project.c`: Prototyping basic file system logic.
- `osystems_file.c`: Operating systems concepts and I/O handling.
- `joint_dynamic_memory.c`: Exploration of dynamic memory allocation and pointer management.

### Fundamentals
- `basics_and_variables.c`, `loop_patterns_modulo.c`, `math_library_logic.c`: Core language features and logic.
- `strings.c`, `structs.c`, `structs_and_arrays.c`: Data management techniques.

## Skills Acquired
- **Memory Safety**: Precise control over pointer arithmetic and allocation.
- **Architectural Awareness**: Understanding CPU instruction cycles and OS-level interactions.
- **Problem Solving**: Translating complex logic into efficient, low-level C code.
