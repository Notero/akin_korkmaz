# Web Applications: Full-Stack Architectures

This directory contains diverse web projects exploring multiple stacks, from traditional LAMP to modern MERN and high-performance WebSocket architectures.

## Project Inventory

- **[contacts_manager_lampstack](./contacts_manager_lampstack)**: A PHP/MySQL-based management system following the classic LAMP paradigm.
- **[idea_board_mernstack](./idea_board_mernstack)**: A collaborative brainstorming platform built with MongoDB, Express, React, and Node.js.
- **[notes_backend_spring](./notes_backend_spring)**: A robust, enterprise-grade RESTful API for note-taking, powered by Java Spring Boot.
- **[uwebsockets](./uwebsockets)**: A high-performance C++ WebSocket server implementation for low-latency communications.

## Educational Focus
- **Full-Stack Development**: Handling both client-side and server-side logic across different ecosystems.
- **Data Persistence**: Interfacing with relational (MySQL) and non-relational (MongoDB) databases.
- **Architecture**: Applying RESTful design principles and real-time communication patterns.
