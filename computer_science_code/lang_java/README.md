# Java Programming: OOP & Algorithms

This directory explores intermediate to advanced concepts in Java, emphasizing object-oriented design and algorithm analysis.

## Directory Inventory

- **[gui-web](./gui-web)**: Graphical user interface and web-based Java applications.
- **[java_spring_api](./java_spring_api)**: Prototyping REST APIs with the Spring framework.
- **[junit_testing](./junit_testing)**: Formal unit testing and test-driven development (TDD) practices.
- **[map / queue_arraylist / stack](./stack)**: Implementation and exploration of various Java collections.
- **[threads](./threads)**: Multi-threaded programming and concurrency control.
- **[unique_pairs](./unique_pairs)**: Algorithmic problem-solving with set-based logic.

## Core File Inventory

### Algorithmic Paradigms
- `backtrack.java`: Recursive backtracking logic for solving combinatorial problems.
- `dynamic_programming.java / dynamic_programming_2.java`: Implementing optimal solutions using memoization and tabulation.
- `greedy_algorithms.java`: Optimization techniques based on local optimal choices.
- `kruskals_algorithm.java`: Minimum spanning tree implementation for graph theory.

### Core Concepts
- `input_output_streams.java`: Handling file I/O and data serialization.

## Academic Development
- **Design Patterns**: Applying OOP principles (Inheritance, Polymorphism, Encapsulation) for modular code.
- **Complexity Analysis**: Understanding Big O notation through practical implementation.
- **Modern Tooling**: Leveraging JUnit for reliability and Spring for scalable web services.
