# Terminal Utilities & Command-Line Tools

A suite of productivity tools and blockchain-interfacing scripts designed for efficient terminal-based workflows.

## Project Inventory

- **[xrp_blockchain_terminal_tools](./xrp_blockchain_terminal_tools)**: A comprehensive set of Node.js-based scripts for interacting with the XRP Ledger via the CLI.
- **`custom_cash_tracker.c`**: A lightweight C-based utility for managing and tracking personal expenses.
- **`todo_list.cs`**: A C#-powered command-line interface for managing tasks and daily goals.

## Core Features
- **Automation**: Streamlines repetitive data entry and blockchain querying tasks.
- **Cross-Platform Utility**: Utilities written in C, C#, and JavaScript for varied runtime environments.
- **Data Persistence**: Local storage of tracking data and task lists for persistence between sessions.
