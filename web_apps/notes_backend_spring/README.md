# Notes Backend: Spring Boot API

A robust, enterprise-grade RESTful API for a note-taking application, built with Java and the Spring Boot framework.

## Project Inventory

- **[src](./src)**: The core Java source code, including controllers, services, repositories, and entities.
- **[gradle](./gradle)**: Project-specific Gradle wrapper files for consistent build environments.
- **`build.gradle`**: The build configuration file containing project dependencies and plugins.
- **`settings.gradle`**: Project settings and module configurations.
- **`gradlew / gradlew.bat`**: The Gradle wrapper scripts for Unix and Windows systems.

## Educational Goals
- **Spring Boot Ecosystem**: Understanding dependency injection, auto-configuration, and Spring Data JPA.
- **RESTful Design**: Implementing standard API endpoints for CRUD operations.
- **Enterprise Patterns**: Applying layered architecture (Controller-Service-Repository) for modularity.

## How-To
- **Build**: Use `./gradlew build` to compile the project and run tests.
- **Execution**: Run the application using `./gradlew bootRun`.
