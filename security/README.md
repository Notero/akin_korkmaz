# Security & Cryptography Implementations

This directory houses C++ implementations of fundamental security and cryptographic algorithms, focusing on data integrity and encryption.

## Project Inventory

- **`checksum_8_16_32.cpp`**: Implementation of various checksum algorithms (8-bit, 16-bit, and 32-bit) used for detecting data transmission errors.
- **`hill_cipher.cpp`**: A matrix-based polyalphabetic substitution cipher that demonstrates linear algebra application in cryptography.

## Educational Goals

- **Data Integrity**: Understanding how checksums verify the correctness of data across a medium.
- **Encryption Logic**: Implementing symmetric encryption through mathematical transforms (Hill Cipher).
- **Security Engineering**: Exploring the trade-offs between computational complexity and security strength.
