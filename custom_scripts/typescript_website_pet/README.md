# TypeScript Website Pet

An interactive and lightweight web component that brings a virtual pet to the browser. This project focuses on TypeScript-driven logic and CSS-based animation to create an engaging user experience.

## Project Inventory

- **[freeCatSprites](./freeCatSprites)**: A collection of image assets and animations representing the pet's different states (e.g., idle, happy, sleeping).
- **`pettable.ts`**: The core TypeScript file implementing the pet's logic, interaction handling, and state management.

## Features
- **Interaction**: Users can interact with the pet via mouse clicks and hovers.
- **State Management**: The pet reacts differently based on its "mood" and previous interactions.
- **Lightweight**: Optimized for fast loading and seamless integration into any web page.
