# Contacts Manager: LAMP Stack

A feature-complete contact management system built using the traditional LAMP stack (Linux, Apache, MySQL, PHP).

## Project Inventory

- **[LAMPAPI](./LAMPAPI)**: The backend API directory containing PHP scripts for CRUD (Create, Read, Update, Delete) operations.
- **[dashboard](./dashboard)**: The main user interface for logged-in users to manage their contacts.
- **[css / js / images](./css)**: Static assets and client-side logic for styling and interactivity.
- **`index.html / login.html / createaccount.html`**: Entry points for authentication and user onboarding.
- **`NebulistAPI.yaml`**: Detailed API documentation following the OpenAPI/Swagger specification.

## Core Features
- **User Authentication**: Secure login and account registration functionality.
- **Contact Management**: Effortlessly search, add, edit, and remove contact records.
- **Database Persistence**: Reliable data storage and retrieval via MySQL.
- **Responsive Design**: Clean and intuitive UI for both desktop and mobile views.

## How-To
- **Deployment**: Requires a web server with PHP support and a MySQL database.
- **Setup**: Import the database schema and configure `LAMPAPI` credentials.
